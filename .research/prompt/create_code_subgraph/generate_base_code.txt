# Experimental Design
- Strategy: ----------------------------------------------------------------
EXPERIMENT 1   “Can NV-ProtoNet lift the ceiling of in-domain few-shot accuracy?”
----------------------------------------------------------------
Goal
• Show absolute accuracy gains and reduced norm variance on the canonical miniImageNet / CIFAR-FS / tieredImageNet 5-way tasks.

Protocol
1. Datasets: miniImageNet, CIFAR-FS, tieredImageNet. 60 000 validation episodes per data set (standard splits).
2. Models
   a) ProtoNet (baseline)
   b) ProtoNet + post-hoc L2 normalisation (popular trick)
   c) NV-ProtoNet (λ ∈ {0,0.05,0.1,0.2,0.4})
3. Backbones: Conv-4 and ResNet-12 (two points on the capacity axis).
4. Training details: identical optimisers, data augmentations, early stopping on validation accuracy. 
   ≈4 GPUs / run, 12 h each, well within the 8 × A100 budget.
5. Measurements (on 10 000 held-out episodes, 95 % CI)
   • mean accuracy (1-shot / 5-shot)
   • embedding-norm variance (per episode & global)
   • run-time per iteration (to verify negligible overhead)

Expected Outcome
• +1-2 pp in 1-shot and +0.5-1 pp in 5-shot across all three data sets vs. baseline; NV-ProtoNet beats post-hoc L2 in every split.
• ≥50 % reduction of norm variance compared with ProtoNet, confirming that the regulariser works as intended.
• Training throughput drop <1 %, proving the method is “free”.

What it demonstrates
Tight, statistically significant improvements on the community’s reference benchmarks with no tuning beyond λ. Lower norm variance directly correlates with higher accuracy, supporting the theoretical motivation.

----------------------------------------------------------------
EXPERIMENT 2   “Does norm-variance control help out-of-domain generalisation?”
----------------------------------------------------------------
Goal
Test the claim that an embedding whose distances depend only on angles transfers better to unseen visual domains.

Protocol
1. Train on miniImageNet only (same setup as Exp 1).
2. Zero-shot cross-domain evaluation on five disjoint fine-grained data sets used by Meta-Dataset: CUB, Cars, Aircraft, QuickDraw, Fungi.
   (Each yields thousands of 5-way 1-shot / 5-shot episodes.)
3. Models: ProtoNet, ProtoNet+L2, NV-ProtoNet (best λ from Exp 1).  ResNet-12 backbone.
4. Metrics: mean episode accuracy, norm variance, and the within-/between-class scatter ratio S_w ⁄ S_b (a proxy for the theory-derived bound).

Expected Outcome
• NV-ProtoNet shows the largest accuracy margin when the target domain distribution is farthest from ImageNet (QuickDraw, Fungi) – e.g. +2-3 pp over baseline, while the in-domain gain was ~1 pp.
• S_w ⁄ S_b is lower for NV-ProtoNet, explaining the stronger transfer.

What it demonstrates
Controlling norm variance is not a mere regulariser that overfits to the source data; it concretely improves domain-shift robustness, highlighting a key strength that simple post-hoc L2 normalisation cannot match.

Example code snippet (PyTorch ≥2.0)
----------------------------------------------------------------
class NVProtoNet(nn.Module):
    def __init__(self, backbone, lambda_var=0.1):
        super().__init__()
        self.encoder = backbone
        self.lambda_var = lambda_var
    def _compute_prototypes(self, emb, targets):
        classes = torch.unique(targets)
        protos  = torch.stack([emb[targets==c].mean(0) for c in classes])
        return protos, classes
    def forward(self, support_x, support_y, query_x, query_y):
        emb_s = self.encoder(support_x)
        emb_q = self.encoder(query_x)
        protos, classes = self._compute_prototypes(emb_s, support_y)
        # pairwise squared L2 distances
        dists = (emb_q[:,None,:]-protos[None,:,:]).pow(2).sum(-1)
        log_p = (-dists).log_softmax(1)
        L_ce  = F.nll_loss(log_p, query_y)
        norms = torch.cat([emb_s, emb_q]).norm(dim=1)
        L_var = norms.var(unbiased=False)
        loss  = L_ce + self.lambda_var*L_var
        return loss, L_ce.item(), L_var.item()
