    "Methodology": "FLUTE's methodology involves training a universal template, which consists of the shared convolutional layer parameters of a ResNet-18 feature extractor. Dataset-specific components are realized as FiLM parameters within batch normalization layers. During training, the feature extractor is jointly trained across M diverse training datasets, maintaining M sets of FiLM parameters for dataset specialization. A cross-entropy loss is minimized for multi-task classification. After this, a 'Blender network' is trained (a permutation-invariant set encoder with a linear readout layer) to act as a dataset classifier. At test time, for a new few-shot task from an unseen dataset, the Blender network generates an initialization for the new FiLM parameters as a convex combination of the trained M sets of FiLM parameters, based on the compatibility between the support set and training datasets. These initialized FiLM parameters are then fine-tuned for a few steps via gradient descent to minimize a Nearest-Centroid Classiﬁer (NCC) loss on the task's support set.
