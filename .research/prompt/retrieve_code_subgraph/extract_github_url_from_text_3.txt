HYPO shapes hyperspherical embedding space to promote domain-invariant representations. The learning objective consists of two main parts: a variation loss (Lvar) to reduce intra-class variation by encouraging sample embeddings to be close to their class prototypes, and a separation loss (Lsep) to maximize inter-class separation by pushing different class prototypes apart. Normalized feature embeddings are used, and class prototype vectors are updated using an Exponential Moving Average (EMA). The loss function is geometrically interpreted as performing maximum likelihood estimation under the von Mises-Fisher (vMF) distribution.
