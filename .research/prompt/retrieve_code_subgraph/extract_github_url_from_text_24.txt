CoPA is built upon a frozen pre-trained ResNet-18 backbone. It adapts two distinct transformation heads: `hθP` for prototypes and `hθI` for image instances, in contrast to prior methods like URL that use a shared transformation. The core learning objective is a symmetric cross-entropy (SCE) loss, commonly used in contrastive learning. The two different transformations preserve discriminative information in gradients and expand the hypothesis space, while the contrastive objective facilitates maintaining and enlarging the modality gap between prototype and image representations, which is shown to improve generalization.
