The method builds upon a classification network (ResNet50/101/38) to extract supervision from image labels and refine CAMs into pseudo-labels for a semantic segmentation network (DeepLabv2). It introduces a unified loss function combining binary cross-entropy for classification and a self-supervised loss for consistency regularization between original CAMs and Prototype-Aware CAMs (PACAMs). The core is prototype awareness: instance prototypes are modeled as anchors using masked average pooling (MAP) from projected features and CAMs. Context prototypes are generated by storing instance prototypes in a support bank, applying k-means online clustering, and averaging clustered groups to form candidate neighbors. Context Prototype-Aware Learning identifies soft positive neighbors using pairwise positiveness scores (calculated via Dot product) to measure relevance and selects the top-K relevant prototypes. Feature distribution alignment introduces a shifting term to instance features, pushing them towards dense feature distributions in the support bank to enhance intra-class compactness. PACAMs are generated by aggregating similarity maps between features and the selected context-aware prototypes.
