The proposed protoLP method iteratively refines prototypes and a learnable graph. It uses a parameterized label prediction step with a linear projection (A) to limit overfitting to the adjacency matrix. A prototype-based graph construction method is introduced where the adjacency matrix (W) is formed from the relation between prototypes and samples (partial assignment Z), allowing the graph to change as prototypes are updated. The model is optimized by alternating updates for assignments (Z), label projection (A), and prototypes (C). Prototypes (C) are initialized as mean vectors of support samples and updated using a weighted average of samples based on soft label scores and an exponential running average. For inference, pseudo-labels are predicted by maximizing soft label scores. Optionally, the Sinkhorn-Knopp algorithm can be used for normalization to incorporate a uniform class prior, though protoLP aims to be robust without it.
