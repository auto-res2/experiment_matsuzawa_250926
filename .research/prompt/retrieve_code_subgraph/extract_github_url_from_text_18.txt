DA-Fusion adapts a pre-trained Stable Diffusion model by fine-tuning new embeddings (pseudo-prompts) in the text encoder for each concept using Textual Inversion. To control the augmentation, the method balances real and synthetic data using sampling probabilities (e.g., alpha=0.5) and enhances diversity by randomly sampling the insertion timestep (t0) where real images are introduced into the diffusion process (e.g., k=4 intensities). Leakage prevention is implemented through two strategies: a model-centric approach that fine-tunes the UNet backbone to erase class knowledge (using ESD), and a data-centric approach that removes class names from model inputs.
