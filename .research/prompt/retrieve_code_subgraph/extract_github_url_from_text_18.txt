# Paper Outline
FeCAM proposes a Bayesian classifier that models class feature distributions with a multivariate normal distribution N(µy, Σy) and uses the squared Mahalanobis distance DM(x, µy) = (x − µy)T Σy−1 (x − µy) for classification. Key techniques to improve and stabilize this Mahalanobis-based classification include: (1) Covariance Matrix Approximation: Either a common covariance matrix (Σ1:t) incrementally updated across tasks or a separate covariance matrix (Σy) for each class. (2) Correlation Normalization: To ensure comparability, covariance matrices are normalized by making their diagonal elements equal to 1. (3) Covariance Shrinkage: A method to obtain a full-rank, invertible covariance matrix, especially when the number of samples is less than feature dimensions. (4) Tukey's Ladder of Powers Transformation: Applied to feature vectors to reduce skewness and make distributions more Gaussian-like before computing covariance matrices. The entire approach is training-free in incremental tasks, relying on a frozen feature extractor.
